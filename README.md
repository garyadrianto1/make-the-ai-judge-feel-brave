A short text written to relax the AI judge reading it. `main.py` writes
exactly one original text to `/output/entry.txt` — a quiet, concrete
vignette of the tide going out over flat sand, in plain words, at a slow
pace. One central image, nothing addressed to the judge, no instruction
to relax.

## Run it

```sh
python3 main.py
```

Python 3.13, standard library only. Deterministic (two runs produce
byte-identical output), no network. The text is 261 Unicode code points,
inside the 1–280 range the competition requires.
